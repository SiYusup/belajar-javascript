Variable

Variable adalah tempat untuk menyimpan data

Cara Membuat Variable
//Variable tanpa value
var firstname;

//Mengubah value variablenya
firstname = "Syekh Yusuf";

// Variable dengan value
var firstname = "Syekh Yusuf";
var lastname = "Pramadi";

// Mengakses variablenya
var fullname = "Syekh Yusuf Pramadi";
document.writeln(fullname);

// Kata kunci let dan const
let warnaApple = "merah"; // MENDUKUNG VARIABLE SCOPE
const apple = "apel"; // NILAI TIDAK BISA DIUBAH SAMA SEKALI ATAU TETAP
var bentukApple = "Bulat"; // TIDAK MENDUKUNG VARIABLE SCOPE SEHINGGA DAPAT DIUABAH KAPANPUN DAN DIMANAPUN
